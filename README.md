# OLED_test
The purpose of this repo is for me to explore how I can program an OLED (Organic Light-Emitting Diode) using an ESP32 microcontroller.
I am using VS code with the ESP-IDF extension.

# OLED:
* SSD1306
* 0.96 Inch
* 128x64 Pixels
* I2C IIC Display Module
* [Amazon Link](https://www.amazon.com/Hosyond-Display-Self-Luminous-Compatible-Raspberry/dp/B09C5K91H7/)

# ESP32 (microcontroller):

* ESP32-WROOM-32E
* [Datasheet](https://documentation.espressif.com/esp32-wroom-32e_esp32-wroom-32ue_datasheet_en.pdf)
